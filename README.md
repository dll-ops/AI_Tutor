# AI Tutor

计划开发面向大学课程学习的AI教学系统，重点关注教师审核的标准答案、分阶段提示、主动学习反馈和程序级教学流程控制。

项目设计参考：Kestin等，*AI tutoring outperforms in-class active learning: an RCT introducing a novel research-based design in an authentic educational setting*，Scientific Reports（2025）。[原论文](https://doi.org/10.1038/s41598-025-97652-6)。

本项目为独立计划，与哈佛大学没有官方隶属关系。目前尚未发布软件实现。
